## ЛЕГЕНДА ДОКУМЕНТА

### Условные обозначения:

**Время:**
- `[09:00]` — игровое время
- `(R: 00:00)` — реальное время от старта

**Типы сообщений:**
- 📨 **INFO** — информационное (не требует ответа)
- ❓ **REQUEST** — запрос (требует выбора ответа)
- 🔥 **ALERT** — критичное (срочное)
- 💬 **RESPONSE** — автоматический ответ/последствие

**Статусы:**
- 🟢 Нормально
- 🟡 Требует внимания
- 🔴 Критично
- ⏰ Эскалация (если игнорировать)

**Ресурсы:**
- ⏱️ — время (в игровых минутах)
- ⚡ — энергия (в процентах)
- 😊 / 😐 / 😔 — влияние на настроение персонажа

## ТЕХНИЧЕСКИЕ ДЕТАЛИ РЕАЛИЗАЦИИ

### Система времени

```javascript
// Псевдокод
const REAL_TIME_DURATION = 12 * 60; // 12 минут
const GAME_TIME_DURATION = 9 * 60; // 9 часов (540 минут)
const TIME_MULTIPLIER = GAME_TIME_DURATION / REAL_TIME_DURATION; // 45x

// Таймер обновляется каждую секунду реального времени
setInterval(() => {
  realTimeElapsed += 1; // секунды
  gameTimeElapsed = realTimeElapsed * TIME_MULTIPLIER / 60; // игровые минуты
  
  currentGameTime = START_TIME + gameTimeElapsed; // 9:00 + elapsed
  
  updateTimer(currentGameTime);
  checkForScheduledMessages(currentGameTime);
  checkEscalations(currentGameTime);
}, 1000);
```

### Система энергии

```javascript
// Начальная энергия
let playerEnergy = 100;

// При действии
function performAction(action) {
  playerEnergy -= action.energyCost;
  
  if (playerEnergy <= 0) {
    triggerGameOver("burnout");
  }
  
  if (playerEnergy < 20) {
    showWarning("Ты на грани выгорания!");
    applyLowEnergyPenalty(); // +50% время на действия
  }
}

// Восстановление (обед)
function lunch(type) {
  if (type === "full") {
    playerEnergy += 25;
  } else if (type === "quick") {
    playerEnergy += 15;
  }
  // type === "skip" → штраф на весь день
}
```

### Система сообщений

```javascript
// Расписание сообщений
const messageSchedule = [
  { time: "09:03", channel: "#general", from: "Денис", type: "info", ... },
  { time: "09:10", channel: "DM_Denis", from: "Денис", type: "request", ... },
  // ...
];

// Проверка расписания
function checkForScheduledMessages(currentTime) {
  const pending = messageSchedule.filter(msg => 
    msg.time <= currentTime && !msg.sent
  );
  
  pending.forEach(msg => {
    showMessage(msg);
    msg.sent = true;
  });
}
```

### Система эскалаций

```javascript
// Отслеживание неотвеченных сообщений
const unansweredMessages = [];

function trackUnansweredMessage(message) {
  unansweredMessages.push({
    message: message,
    sentAt: currentGameTime,
    escalationTime: message.escalationDelay
  });
}

function checkEscalations(currentTime) {
  unansweredMessages.forEach(item => {
    const elapsed = currentTime - item.sentAt;
    
    if (elapsed >= item.escalationTime) {
      triggerEscalation(item.message);
    }
  });
}
```

### Система последствий

```javascript
// Последствия хранятся как "отложенные сообщения"
function makeChoice(choice) {
  // Немедленные эффекты
  playerEnergy -= choice.energyCost;
  gameTime += choice.timeCost;
  
  // Отложенные последствия
  choice.consequences.forEach(consequence => {
    scheduleMessage({
      time: gameTime + consequence.delay,
      ...consequence.message
    });
  });
  
  // Влияние на персонажей
  updateCharacterState(choice.affectedCharacter, choice.moodChange);
}
```
