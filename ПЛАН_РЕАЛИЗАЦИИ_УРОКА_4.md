# 🚀 Пошаговый план реализации Урока 4: Симулятор Мессенджера

## 📌 Обзор
**Название:** Урок 4: Коммуникация в мессенджере
**Тип:** Симулятор чата (Messenger Simulator)
**Цель:** Научить пользователя эффективно общаться в рабочих чатах, приоритизировать сообщения и управлять временем.

---

## 📋 Этап 1: Подготовка данных (1 час)

### 1.1 Обновить `data/lessons.json`
Добавить конфигурацию Урока 4 в массив `lessons`.

```json
{
  "id": 4,
  "title": "Урок 4: Коммуникация в мессенджере",
  "description": "Симулятор рабочего дня Team Lead в мессенджере. Учись управлять потоком сообщений и решать проблемы удаленно.",
  "type": "messenger",
  "estimatedTime": "15-20 минут",
  "content": {
    "introText": "Добро пожаловать в симулятор рабочего мессенджера! Твоя задача - пережить рабочий день, отвечая на сообщения коллег. Следи за энергией и временем!"
  }
}
```

### 1.2 Создать `data/messenger-scenarios.json`
Создать файл со сценариями диалогов.

**Структура:**
- `contacts`: Список контактов (имя, роль, аватар, статус)
- `threads`: Цепочки сообщений
- `events`: События по времени (9:00, 10:00 и т.д.)

---

## 💻 Этап 2: Реализация UI (2-3 часа)

### 2.1 Создать `js/messenger-game.js`
Основной класс `MessengerGame` для управления игрой.

**Основные методы:**
- `init(container)`: Инициализация UI
- `renderLayout()`: Создание структуры (Sidebar + Chat Area)
- `renderContactList()`: Отображение списка контактов
- `renderChatWindow(contactId)`: Отображение переписки
- `addMessage(message)`: Добавление сообщения в чат
- `showChoices(choices)`: Отображение вариантов ответа

### 2.2 Стилизация в `css/components.css`
Добавить стили для мессенджера:
- `.messenger-layout`: Grid layout (30% sidebar, 70% chat)
- `.contact-list`: Список контактов со статусами
- `.chat-window`: Область переписки
- `.message-bubble`: Стили сообщений (свои/чужие)
- `.typing-indicator`: Анимация печати
- `.choice-area`: Область выбора ответов

---

## 🎮 Этап 3: Игровая логика (2 часа)

### 3.1 Система времени и энергии
- Таймер рабочего дня (9:00 - 18:00)
- Шкала энергии (уменьшается от сложных ответов)
- Шкала стресса (растет от игнорирования срочных сообщений)

### 3.2 Обработка событий
- Триггеры сообщений по времени
- Блокирующие события (например, "Срочный баг")
- Влияние выборов на отношения с коллегами
