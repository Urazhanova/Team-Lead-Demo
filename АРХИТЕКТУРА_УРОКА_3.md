## 🎮 State Machine: Переходы между Фазами

```
                          ┌─────────────┐
                          │ INTRO PHASE │
                          └──────┬──────┘
                                 │
                    ┌─ Click "Начать игру"
                    │            ▼
        ┌───────────────────────────────────────┐
        │      GAME PHASE (Main Gameplay)        │
        │                                        │
        │  1. Load tasks from sprint-tasks.json │
        │  2. Render game board                 │
        │  3. Handle user interactions:         │
        │     - Select task                     │
        │     - Remove task                     │
        │     - View task details               │
        │  4. Update capacity meter             │
        │                                        │
        └───────────────────────┬────────────────┘
                                │
                ┌─ Click "Завершить спринт"
                │                ▼
        ┌──────────────────────────────────┐
        │   REVIEW PHASE (Validation)      │
        │                                  │
        │  1. Validate selection:          │
        │     - All critical tasks?        │
        │     - Tech debt included?        │
        │     - Good balance?              │
        │     - Not overcapacity?          │
        │                                  │
        │  2. Calculate score (0-100):     │
        │     - Each criterion: +25%       │
        │                                  │
        │  3. Generate feedback message    │
        │                                  │
        └──────────┬───────────────────────┘
                   │
        ┌─ User accepts result
        │          ▼
        ┌────────────────────────────────┐
        │  RESULTS PHASE (Celebration)   │
        │                                │
        │  1. Show score (X/100)         │
        │  2. Show analysis              │
        │  3. Update skill bars          │
        │  4. Unlock achievements        │
        │  5. Award XP                   │
        │  6. Show next lesson button    │
        │                                │
        └───────────┬──────────────────┘
                    │
        ┌─ Click "Следующий урок"
        │            ▼
        └───────► Next Lesson
                    OR
        ┌─ Click "← Переделать"
        │            ▼
        └───────► GAME PHASE (reset)
```

### 1. Navigation Integration

  GameContent.render(self.currentLesson, mainContent);
}

// GameContent handles all game logic after this

### 2. SCORM Integration

```javascript
// In GameContent.completeGame():

// Log interaction
SCORM.addInteraction(
  'sprint-planning-' + this.gameState.sprintId,
  'choice',
  this.gameState.selectedTasks.join(','),
  this.gameState.score >= 75
);

// Set score
SCORM.setValue(
  'cmi.core.score.raw',
  Math.round(this.gameState.score)
);

// Commit to LMS
SCORM.commit();
```
