## 🚀 Быстрый старт

### 1. Запуск локально

```bash
# Перейти в папку проекта
cd ~/Desktop/team-lead-academy-scorm

# Запустить локальный сервер
python3 -m http.server 8001

# Открыть в браузере
# http://localhost:8001
```

### 2. Использование Debug консоли

- Нажми кнопку **🐛** в нижнем правом углу
- Посмотри логи загрузки и работы приложения
- Используй для отладки вместо DevTools консоли

### 3. Навигация по уроках

- Нажми **☰** (гамбургер меню) в верхнем правом углу
- Выбери урок из списка
- Используй кнопки "Далее" и "Назад" для навигации

## 🛠 Разработка

### ⚠️ ПРАВИЛО РАЗРАБОТКИ: Работа только с Уроком 3

**Все изменения, которые могут повлиять на другие уроки или системные компоненты, должны быть согласованы перед внесением!**

Примеры таких изменений:
- Редактирование `css/variables.css` или глобальных CSS файлов
- Изменения в `js/game-2d.js` или `js/navigation.js`
- Модификация структуры `data/lessons.json`
- Изменения в HTML логике в `index.html`

### Добавление нового урока

1. Открыть `data/lessons.json`
2. Добавить новый объект в массив `lessons`
3. Определить экраны (`screens`) с типом и контентом
4. Перезагрузить браузер

### Изменение стилей

1. Отредактировать `css/variables.css` (цвета, размеры)
2. Обновить `css/components.css` (компоненты)
3. Изменить `css/layouts.css` (макеты)
4. Стили применяются автоматически

### Добавление изображений

1. Добавить файлы в `assets/images/`
2. Указать путь в `data/lessons.json`
3. Использовать путь вида: `assets/images/scenes/имя-файла.png`
