**Цель:** Научить пользователей приоритизировать задачи, управлять ресурсами команды и принимать сложные решения в контексте спринт-планирования.

---

## 🎮 Концепция Игры: Sprint Planning Simulator

### Основная Идея
Пользователь становится Team Lead, который должен спланировать спринт для своей команды. Ему даются:
- **Доступная пропускная способность:** 40 story points (объем работы на спринт)
- **Набор задач:** 10-12 задач разного размера (5-10 story points каждая)
- **Разные приоритеты:** Business, Technical, Customer
- **Сроки:** Есть задачи, которые НУЖНО сделать в этом спринте

**Задача игрока:** Выбрать оптимальный набор задач, чтобы:
1. Уложиться в пропускную способность (≤40 points)
2. Удовлетворить главные приоритеты business
3. Включить technical debt работу
4. Сбалансировать разные типы задач

## 🏗️ Архитектура: 4 Фазы Игры

### Фаза 1: INTRO (Экран Введения)
**Расположение:** `GameContent.render()` - существующий экран
**Контент:**
- Заголовок: "Планирование спринта"
- Текст введения с целями игры
- Кнопка "Начать игру"

### Фаза 2: GAME_PHASE (Основная Игровая Механика)
**Расположение:** `GameContent.startGame()` → спринт-планирование
**Структура:**
```
┌─────────────────────────────────────┐
│ Sprint Planning: Week 3             │  ← Header с информацией
│ Capacity: 40/40 story points        │
├─────────────────────────────────────┤
│                                     │
│ ╔══════════════╗  ╔══════════════╗ │
│ ║ Task Card 1  ║  ║ Task Card 2  ║ │  ← Available Tasks (слева)
│ ║ 8 points     ║  ║ 5 points     ║ │
│ ║ 🔴 Critical  ║  ║ 🟡 Important ║ │
│ ╚══════════════╝  ╚══════════════╝ │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ YOUR SPRINT PLAN                │ │  ← Sprint Board (справа)
│ │ ─────────────────────────────    │ │
│ │ [Task 1] → 8 points             │ │
│ │ [Task 3] → 6 points             │ │
│ │ [Task 5] → 5 points             │ │
│ │ ─────────────────────────────    │ │
│ │ Total: 19/40 points             │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [Предыдущий] [Завершить Спринт] →  │
└─────────────────────────────────────┘
```

**Механика:**
- Drag-and-drop задачи из доступных в спринт-план
- Динамическое обновление счётчика points
- Валидация: невозможно добавить, если превышит capacity
- Кнопка "Remove" для каждой задачи в плане
- При клике на задачу → модальное окно с деталями
