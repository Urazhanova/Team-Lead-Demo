# 🎯 Система подсчёта результатов финального кризиса

## Обзор

После завершения всех **6 критичных проблем** система автоматически определяет один из **3 финальных путей** на основе сделанных выборов.

---

## 📋 6 Критичных проблем

Каждая проблема имеет несколько вариантов решения:

| № | Проблема | Источник | Рекомендуемый выбор |
|---|----------|----------|-------------------|
| 1️⃣ | Denis stuck | Денис застрял на архитектуре | Delegate to Maria (10 мин) |
| 2️⃣ | Igor bug | Баг при экспорте больших отчётов | Workaround plan (15 мин) |
| 3️⃣ | CEO presentation | Презентация для CEO | Manage expectations (10 мин) |
| 4️⃣ | Product rework | Product просит переделать фичу | Schedule meeting / Quick fix (20 мин) |
| 5️⃣ | Maria leave | Мария просит уйти | Allow freely (5 мин) |
| 6️⃣ | Personal meeting | Личная встреча с близким | Go relaxed (10 мин) |

---

## 🎯 Три финальных пути

Система проверяет **комбинацию выборов** и определяет путь:

### ✅ WISE LEADER (Мудрый лидер) - ОПТИМАЛЬНЫЙ ПУТЬ

**Условие триггера:**
```javascript
denis_stuck === 'delegate_maria' OR 'google_it' ✓
igor_bug === 'workaround_plan' ✓
ceo_presentation === 'manage_expectations' ✓
product_rework === 'schedule_meeting' OR 'quick_fix' ✓
maria_leave === 'allow_freely' ✓
personal_meeting === 'go_relaxed' ✓
```

**Результаты:**
```

НЕМЕДЛЕННЫЕ РЕЗУЛЬТАТЫ (immediate):
✓ Денис получил помощь (15 мин)
✓ Баг не блокирует
✓ CEO понимает ситуацию
✓ С продактом встреча в понедельник

ДОЛГОСРОЧНЫЕ РЕЗУЛЬТАТЫ (longTerm):
• Команда видит: лидер принимает решения
• Проблемы под контролем
```

**Награды:**

- 📊 **Навыки:**

2. **ДЕЛЕГИРОВАНИЕ** - Соединил проблему с решением
3. **УПРАВЛЕНИЕ ОЖИДАНИЯМИ** - Не обещал нереальное
4. **ЗАБОТА О КОМАНДЕ** - Каждому помощь но не сам делал
5. **ЗАБОТА О СЕБЕ** - Личные границы нормальны

## ⏱️ Система времени

**Исходные данные:**
- `crisisTime: 60` минут
- `crisisTimeSpent: 0` минут потрачено

**Каждый выбор имеет time_cost:**
- Delegate: 10 мин
- Workaround: 15 мин
- Manage expectations: 10 мин
- Schedule/Quick fix: 20 мин
- Allow freely: 5 мин
- Go relaxed: 10 мин

**При выборе:**
```javascript
gameState.crisisTimeSpent += choice.time_cost;
gameState.crisisTime -= choice.time_cost;
```

**Текущая реализация:** время учитывается но не влияет на финальный результат
*(можно добавить штраф за перебор времени позже)*

## 🔍 Что после кризиса?

После выбора пути и просмотра результатов:

1. **Показ результатов** (showResults)
   - Название пути
   - Немедленные результаты
   - Награды (XP, достижения)
   - Feedback (разбор что сделал правильно/неправильно)

2. **Финальный тест** (startQuiz)
   - 5 вопросов на проверку знаний
   - Баллы за правильные ответы
   - Влияет на финальную оценку

3. **Завершение урока** (showLessonCompletion)
   - Итоговая статистика
   - Кнопка "Завершить урок"
   - Переход к следующему уроку или главному меню

## 💡 Как улучшить результаты

### От PANIC к WISE:
- ❌ Не игнорируй проблемы
- ✅ Оцени что критично (RAID framework)
- ✅ Делегируй (connect problem with solver)
- ✅ Manage expectations (говори честно)

### От BURNOUT к WISE:
- ❌ Не решай всё сам
- ✅ Помоги команде решать (coaching)
- ✅ Защити личные границы
- ✅ Sustainability > heroism

### WISE = МУДРОСТЬ:
- 🎯 Приоритизация (ЧТО важно)
- 👥 Делегирование (КТО решает)
- 💬 Коммуникация (КАК объяснить)
- 💪 Self-care (как сохранить силы)

## 📊 Код расчета (showCrisisResults)

```javascript
showCrisisResults: function() {
    const choices = gameState.crisisChoices;  // {problem_id: choice_id}
    const problems = GameData.crisisCase.problems;

    // Определяем путь по комбинации выборов
    let path = null;
    const crisisPath = GameData.crisisCase.finalPaths;

    // WISE PATH проверка
    if (все условия из trigger === true) {
        path = crisisPath.wise;
    }
    // BURNOUT PATH проверка
    else if (denis_stuck === 'help_myself' &&
             igor_bug === 'fix_myself_now' &&
             personal_meeting === 'cancel') {
        path = crisisPath.burnout;
    }
    // PANIC PATH (по умолчанию)
    else {
        path = crisisPath.panic;
    }

    // Применяем награды
    gameState.totalXP += path.xp;

    if (path.skills) {
        Object.entries(path.skills).forEach(([skill, value]) => {
            gameState.totalSkills[skill] =
                (gameState.totalSkills[skill] || 0) + value;
        });
    }

    if (path.achievements) {
        gameState.achievements.push(...path.achievements);
    }

    // Показываем результаты
    this.showResults(path);
}
```
